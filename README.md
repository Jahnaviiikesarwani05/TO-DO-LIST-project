# 📝 To-Do List Application

A simple To-Do List application developed in Java that helps users manage their daily tasks efficiently. Users can add, update, delete, and mark tasks as completed through an easy-to-use interface.

---

## 📌 Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 📋 View all tasks
- 🎨 Simple and user-friendly interface

---

## 🛠️ Technologies Used

- JAVA
- AWT / Swing (depending on your project)
- Object-Oriented Programming (OOP)

## ▶️ How to Run this

1. Clone the repository

```bash
git clone https://github.com/your-username/ToDoList.git
```

2. Open the project in your Java IDE (Eclipse, IntelliJ IDEA, or VS Code).

3. Compile the project.

4. Run the main Java file.
